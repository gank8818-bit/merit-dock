# Merit Dock — website

Landing page for **Merit Dock**, a personal study agent for Schoology students on iPhone, iPad, and Mac.

- Live: https://gank8818-bit.github.io/merit-dock/
- App Store: https://apps.apple.com/app/id6788785812
- Pages: `index.html` (self-contained), `privacy.html`, `terms.html`, `support.html` (styled by `legal.css`)

Design: "riso study zine". Flat vector shapes in two risograph inks (fluoro pink `#FF4FA3`, ultramarine `#2536C9`) on sunflower `#FFE14A` or white paper; overlaps overprint with `mix-blend-mode`. One typeface, Bricolage Grotesque (OFL), self-hosted in `fonts/` so the site makes no third-party requests. Motion prints the page (headline wipe, pink check stroke, chat sequence, scroll overprints) and is fully disabled under `prefers-reduced-motion`.

Served from GitHub Pages; `.nojekyll` keeps files as-is.
