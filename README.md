# Merit Dock — website

Landing page for **Merit Dock**, a personal study agent for Schoology students on iPhone, iPad, and Mac.

- Live: https://gank8818-bit.github.io/merit-dock/
- App Store: https://apps.apple.com/app/id6788785812
- Pages: `index.html` (self-contained), `privacy.html`, `terms.html`, `support.html` (styled by `legal.css`)

Design: "deep water", built from the app icon (a checkmark riding on waves). Cobalt sea `#2459E8` and deep-water navy `#0A1A52` bands, sea-glass mint waves `#7EF0C9`, a buoy-orange checkmark and buttons `#FF6A3D`, and pale foam `#E9F8F2` reading sections. Flat vector shapes that overprint where they overlap. One typeface, Bricolage Grotesque (OFL), self-hosted in `fonts/` so the site makes no third-party requests. Motion: rolling hero waves, the headline wipe and orange check stroke, the Ask Merit chat sequence, scroll-driven shapes and the stamp. All of it is disabled under `prefers-reduced-motion`.

Served from GitHub Pages; `.nojekyll` keeps files as-is.
